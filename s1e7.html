Dependabot, three ways

  • 🚨Dependabot alertsTell you when a dependency has a known vulnerability
  • 🩹Security updatesOpen a pull request that moves to a fixed version
  • 🗓️Version updatesScheduled pull requests from .github/dependabot.yml, GitHub Actions included

Maya Dependabot alerts tell you when a package you use has a known vulnerability.

Maya Security updates go one step further: Dependabot opens a pull request that moves to a fixed version.

Maya And version updates keep everything current on a schedule you set, your GitHub Actions too.

Rusty N-no! Not a pull request!

POOF!

Dewi So I just merge Dependabot's pull request?

Maya Once the checks pass. And read the release notes: a major version jump can break things. That's why CI matters.

Dewi How much does Dependabot cost?

Maya Alerts, security updates and version updates are free on every repository.

Bit Bonus: you can even assign a Dependabot alert to Copilot and let it work on a fix.

.github/dependabot.yml

version: 2
updates:
  - package-ecosystem: "npm"
    directory: "/"
    schedule:
      interval: "weekly"
  - package-ecosystem: "github-actions"
    directory: "/"
    schedule:
      interval: "weekly"

Maya This file asks for weekly updates for our npm packages and for the actions in our workflows.

Dependabot security updates. Correct! Alerts warn you; security updates open the fix.

What you learned

  • Dependabot alerts warn you when a dependency has a known vulnerability. Security updates open a pull request that moves to a fixed version.
  • Version updates keep packages and GitHub Actions current, on the schedule you set in .github/dependabot.yml.
  • Alerts, security updates and version updates are free on every repository. Merge once the checks pass, and read the release notes for major versions.
