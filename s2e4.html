Quiz: Why did gh pr edit --add-reviewer @copilot fail the first time?

  1. The pull request was already merged
  2. It was pasted into Copilot CLI, where @ starts a file reference
  3. Copilot was busy
Show the answer

It was pasted into Copilot CLI, where @ starts a file reference. Right. Commands in bash, prompts in Copilot CLI.

What you learned

  • Request the Copilot review while the pull request is still open: from the Reviewers menu, or from the bash terminal, never from inside Copilot CLI.
  • Act on each comment, or explain why not. A clean review still leaves the approval to you.
  • The main-review ruleset makes Copilot review every new pull request to main. Merge with a squash and the Careers page deploys.
