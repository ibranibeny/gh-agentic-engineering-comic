# Ship It, Dewi!

An interactive anime comic about GitHub, GitHub Copilot and the agent-native SDLC.

**Read it:** https://ibranibeny.github.io/gh-agentic-engineering-comic/

An interactive, click-through anime comic in two parts:

* **Season 1, Learn the concepts:** GitHub and GitHub Copilot; issues, pull requests and CI/CD; GitHub Actions; GitHub Agentic Workflows; Copilot Fusion; Copilot code review; Dependabot; GitHub Advanced Security.
* **Season 2, The workshop story:** the seven chapters of the hands-on workshop [Ship Contoso's company profile the agent-native way](https://ibranibeny.github.io/gh-agentic-engineering-workshop/), with real screenshots and the key commands.

Tap or click to advance, press the left arrow to go back, `L` for the story log, `A` for auto-play, `T` for the text version and `F` for full screen. Every episode also has a plain text version.

Contoso and all characters are fictional. Artwork was generated with AI for this comic. Facts link to GitHub Docs, the GitHub Changelog and github.com (checked 14 November 2026). Not an official GitHub publication.
