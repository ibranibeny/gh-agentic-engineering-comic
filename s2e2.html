Install the agentic workflows CLI and set up the repo

>_ Bash terminal · not Copilot CLI
gh extension install github/gh-aw \
  || curl -sL https://raw.githubusercontent.com/github/gh-aw/main/install-gh-aw.sh | bash
gh aw version
gh aw init

Maya Some accounts hit a single sign-on block on the extension check. The install script after the || is the fallback, and it needs no token.

In the bash terminal. Right. Commands in bash, prompts in Copilot CLI.

What you learned

  • A codespace is a ready cloud development environment built from the repository's dev container: Node.js 22 and the GitHub CLI, nothing to install.
  • Install gh-aw, run gh aw init, then describe the triage agent to Copilot CLI in plain language. Review the workflow it writes, check its safe outputs, then push.
  • Keep two terminals: bash for commands, Copilot CLI for prompts. Never paste a command into Copilot CLI.
