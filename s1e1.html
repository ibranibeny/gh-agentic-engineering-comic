Git and GitHub are not the same thing

🧭 Git

The version-control system. It records every change as a commit.

  • Branches let people work in parallel
  • Every clone carries the full history

🏠 GitHub

The cloud home for Git repositories, plus everything around the code.

  • Issues and Projects to plan
  • Pull requests to review
  • Actions to automate
  • Security and Copilot built in

📁 Repository = your project's files plus their whole history.

Maya Git is the engine. It records each change as a commit, and branches let people work in parallel.

Maya GitHub hosts those repositories in the cloud and adds planning, review, automation and security.

Dewi And a repository is the project plus its whole history. Got it!

GitHub Copilot today

Quiz: Which sentence is true?

  1. GitHub is the version-control system, and Git is the website.
  2. Git records the history; GitHub hosts repositories and adds collaboration, automation and security.
  3. You can't use Git without GitHub.
Show the answer

Git records the history; GitHub hosts repositories and adds collaboration, automation and security.. Exactly. Git is the engine; GitHub is the whole workshop built around it.

What you learned

  • Git records every change as a commit, on branches you can work on in parallel. GitHub hosts Git repositories in the cloud and adds planning, review, automation and security.
  • GitHub Copilot helps in your editor, in the terminal with Copilot CLI, on github.com, in GitHub Mobile and in the GitHub Copilot app.
  • Copilot cloud agent takes an issue and opens a pull request, and Copilot code review reviews pull requests. People stay in charge of what merges.
