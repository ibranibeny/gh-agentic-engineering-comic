Quiz: Which publishing source does the workshop choose in Settings → Pages?

  1. Deploy from the main branch
  2. GitHub Actions, so the workflow tests and builds before it deploys
  3. A wiki page
Show the answer

GitHub Actions, so the workflow tests and builds before it deploys. Yes. The workflow tests and builds first, then deploys.

What you learned

  • Create your own public repository from the starter template: the site, the tests, a Pages workflow and a dev container are already in it.
  • Set Settings → Pages → Source to GitHub Actions, then run the deploy workflow. A red first run is expected: Pages was still off when the repository was created.
  • A public repository gets GitHub Pages, CodeQL, secret scanning, push protection and Dependabot at no cost.
