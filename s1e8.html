What you learned

  • GitHub Secret Protection: push protection blocks secrets before they land, and secret scanning searches the full Git history.
  • GitHub Code Security: CodeQL finds vulnerabilities by following the data, and Copilot Autofix proposes a patch for you to review.
  • For GitHub Team and Enterprise each costs a monthly fee per active committer (US$19 and US$30). Public repositories get code scanning, secret scanning, push protection and Autofix free.
