Getting a Copilot review

  • 👤On requestPull request → Reviewers → Copilot
  • 📏AutomaticallyA ruleset rule: "Automatically request Copilot code review"
  • 📘Your house rules.github/copilot-instructions.md and path-specific *.instructions.md files

Quiz: Your team wants a Copilot review on every pull request, without anyone remembering to ask. What do you set up?

  1. A weekly reminder in the team chat
  2. A ruleset with "Automatically request Copilot code review"
  3. Make Copilot a repository admin
Show the answer

A ruleset with "Automatically request Copilot code review". Yes. One ruleset, and every new pull request gets a Copilot review.

What you learned

  • Request a review by picking Copilot in the pull request's Reviewers menu, or make it automatic with a ruleset rule.
  • Copilot follows .github/copilot-instructions.md and path-specific instructions files. You decide which suggestions to apply.
  • Copilot leaves comment reviews and never blocks a merge; it approves only if you opt in. Reviews use AI credits plus Actions minutes and need a paid Copilot plan.
