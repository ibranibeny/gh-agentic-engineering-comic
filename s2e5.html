Show the answer

A draft pull request with the fix. Yes. A draft pull request: mark it ready, let the checks pass, then merge.

What you learned

  • Turn on CodeQL default setup in Settings → Advanced Security. The first analysis finds the cross-site scripting bug in the legacy newsroom search.
  • Copilot Autofix proposes the fix; "Commit to new branch" opens a draft pull request. Mark it ready, let the checks pass, merge, and the alert closes.
  • Push protection blocks a secret before it lands. The workshop uses the dummy token from GitHub's own tutorial, never a real one.
