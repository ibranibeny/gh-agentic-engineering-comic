Quiz: Why does the Fusion prompt say "do not merge"?

  1. Merging needs a different model
  2. Every change gets reviewed before it merges, even one an AI wrote
  3. Pull requests can't be merged from a codespace
Show the answer

Every change gets reviewed before it merges, even one an AI wrote. Exactly. Review first, then merge.

What you learned

  • Switch Copilot CLI to Copilot Fusion with /model, or start it with copilot --model fusion.
  • Hand Copilot the triaged issue as the spec: branch, page, content in src/data/careers.json, tests and a pull request.
  • Approve each action after reading the diff, run the tests, preview on port 8080, and stop before merging: nothing merges unreviewed.
