What you learned

  • Security and quality shows code scanning, secret scanning and Dependabot in one place. In an organization, security overview rolls it up across repositories.
  • On a public repository everything you used is free. Private repositories need GitHub Secret Protection and GitHub Code Security; Dependabot is included; Copilot features run on your Copilot plan and AI credits.
  • The playbook: agents do the busywork, people review and decide, security gates guard main.
