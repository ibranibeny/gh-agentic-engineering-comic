.github/dependabot.yml

version: 2
updates:
  - package-ecosystem: "npm"
    directory: "/"
    schedule:
      interval: "weekly"
    groups:
      npm-dependencies:
        patterns: ["*"]
  - package-ecosystem: "github-actions"
    directory: "/"
    schedule:
      interval: "weekly"
    groups:
      github-actions:
        patterns: ["*"]

Maya Weekly version updates for npm and for GitHub Actions, grouped so each ecosystem arrives as one pull request.

Bundles updates into one pull request per group. Right! One grouped pull request instead of a pile of small ones.

What you learned

  • Turn on Dependabot alerts and security updates. GitHub switches on the dependency graph with them.
  • The critical ejs alert (CVSS 9.8, fixed in 3.1.7) comes with a fix: merge Dependabot's security update once the checks pass.
  • Add .github/dependabot.yml for npm and GitHub Actions. The grouped version updates retire the Node.js 20 warnings from Chapter 1.
