📍 Inside an agentic workflow

How an agentic workflow is built

📝 issue-triage.md

---
on:
  issues:
    types: [opened]
engine: copilot
permissions:
  contents: read
  issues: read
safe-outputs:
  add-labels:
    max-labels: 3
  add-comment:
    max: 1
---
# Issue triage
Read the new issue. Add 1 to 3 labels
from the allowed list, then post one
comment with the files likely to change.

⚙️ gh aw compile

Turns the Markdown into issue-triage.lock.yml, a hardened GitHub Actions workflow.

An engine runs it on GitHub-hosted runners. GitHub Copilot is the default.

Maya The frontmatter sets the trigger, the permissions, the tools and the outputs the agent may ask for.

Safe outputs: the agent asks, a separate job acts

  1. 🤖 Agent jobread-only permissions
  2. 📮 Safe outputs"add these labels", "post this comment"
  3. 🛡️ Detection jobchecks the requests for threats
  4. ✅ Apply jobwrites them, within the limits you declared

Maya The agent job can only read. It can't write anything itself.

Maya It requests writes as safe outputs: add a label, post a comment, open a pull request.

Maya A detection job checks those requests first. Then a separate job applies them, within the limits you declared.

Raka Read-only agent. Checked outputs. Declared limits. ...Fine. I approve.

Dewi Does it need a special token to call Copilot?

Maya Add copilot-requests: write to the permissions, and it uses the built-in GITHUB_TOKEN. No personal access token to manage.

Quiz: In an agentic workflow, how does the agent add a label to an issue?

  1. It calls the GitHub API directly with a write token
  2. It requests a safe output, and a separate job applies it after a check
  3. It emails a maintainer and asks
Show the answer

It requests a safe output, and a separate job applies it after a check. Correct. The agent only asks. A separate, checked job does the writing.

What you learned

  • GitHub Agentic Workflows are written in Markdown: YAML frontmatter for the trigger, permissions, tools and safe outputs, then plain-language instructions.
  • gh aw compile turns the file into a hardened GitHub Actions workflow (a .lock.yml file). GitHub Copilot is the default engine.
  • The agent can only read. Writes such as labels and comments are requested as safe outputs, checked by a detection job and applied by a separate job.
